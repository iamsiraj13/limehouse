# 🏠 LimeHouse - Multipage HTML5 Template

LimeHouse is a professional-grade responsive template featuring 23 unique pages, cross-browser compatibility, and pixel-perfect UI.

## 🚀 Features
- 23 HTML pages
- Complex layout structure with sliders
- Fully responsive on all devices
- Pixel-perfect design
- Cross-browser compatibility

## 🛠️ Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
